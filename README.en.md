# Practical Experiments — Stellar Testnet + Horizon

[🇧🇷 Português](README.md) | [🇬🇧 English](README.en.md)

Repository of practical master's degree experiments with the **Stellar Testnet** and **Horizon** (API) running in **Docker**. Contains logbooks, ledger/mempool monitoring reports, synchronization analyses, storage optimization studies, and Docker setups (Core + Horizon, MainNet, Core-only).

  - `2026-07-16` — 30/100/500-ledger monitoring, mempool, and transactions
  - `2026-07-17` / `2026-07-20` — Node synchronization and catch-up
  - `2026-07-21` — Implementation plan: Core + Horizon split, SQL analysis
  - `2026-07-26` — Validator storage optimization
  - `Docker-Core-Horizon-Separated` / `Docker-MainNet` / `Docker-MainNet-CoreOnly` — Docker setups
