Mempool and Transaction Throughput Analysis on the Stellar Testnet

Experiment: Monitoring of 30 consecutive ledgers | Network: Test SDF Network ; September 2015 | Container: stellar/quickstart:testing | Date: 16/07/2026

Executive Summary

This report presents the analysis of the mempool behavior and transaction throughput on the Stellar Testnet during the monitoring of 30 consecutive ledgers (L#3646628 to L#3646657), covering an approximate period of 150 seconds. Data collection was performed through the local Horizon API (http://localhost:8000) and the HTTP interface of the Stellar Core Node (http://localhost:11626), both operating in the stellar-testnet container. For each ledger, the number of successful and failed transactions, the operations proposed in the Transaction Set (TxSet), the operations actually executed, the evolution of the Fee Pool, and the memory consumption of the stellar-core processes were recorded. The data is presented in six charts, accompanied by a detailed analysis and interpretation of the results in light of the Stellar protocol architecture.

6. Cumulative Operations in the Mempool — Backlog and Trend

Chart legend: The blue line represents the cumulative total of proposed operations (mempool inflow) — for each ledger, the TxSet size is added. The green line represents the cumulative total processed (sum of successful and failed). The dashed yellow line represents the backlog — the difference between what entered and what left. Interpretation: when the yellow line rises, the mempool queue is growing; when it falls, the queue is being drained; when it stays stable, the inflow rate matches the processing rate.

7. Rejected Transactions by Failure Type — Temporal Distribution

Legend: Each line represents a failure category, connecting the points where rejections occurred across the 30 ledgers. The height of each point indicates the absolute number of transactions rejected by that cause in that specific ledger. The categories were obtained by decoding the result_xdr of each failed transaction via stellar-core print-xdr.
